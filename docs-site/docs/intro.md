# Introduction

react-f0rm is a lightweight, event-driven React form library with fine-grained tree-shaking support.

## Features

- **Event-driven** — efficient updates via event emitter
- **Tree-shakeable** — only pay for features you use
- **TypeScript** — full type coverage
- **Tiny** — ~3KB gzipped
- **Schema validation** — Zod, Yup adapters included
